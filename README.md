# AnyGame

## 부캉이 북항 탈출

부산 북항 친수공원 인공수로에 들어온 흑상어 **부캉이**를 방파제 너머 바다까지 탈출시키는 3D 3레인 러너 게임입니다.

- 좌우 스와이프(← → / A·D)로 라인 이동, 위로 스와이프(↑ / W / Space)는 점프, 아래로 스와이프(↓ / S)는 잠수입니다.
- 장애물마다 피격 범위(수면 표시 + 반투명 박스 + 아이콘)가 색으로 표시됩니다.
  - 빨강 = 피해야 함(부표, 물펌프), 파랑 = 잠수로 통과(그물, 구조 보트), 노랑 = 점프로 통과(부유물, 오일펜스는 잠수도 가능)
- 고등어를 먹으면 점수, 세 번 부딪히면 실패합니다.
- 총 1,400 m: 친수공원 수로(0–1,040 m) → 북항 → 방파제 등대 사이(1,400 m) 통과 시 성공.

`index.html` 하나로 동작합니다(Three.js r128을 cdnjs에서 불러옴). 빌드 과정이 없습니다.

### 실행
- 로컬: `index.html`을 브라우저로 열거나 `python3 -m http.server` 후 접속.
- 공유: GitHub 저장소 Settings → Pages → Branch를 이 파일이 있는 브랜치로 지정하면 `https://<사용자>.github.io/AnyGame/` 주소로 누구나 플레이할 수 있습니다.
