# AnyGame

## 부캉이 북항 탈출

부산 북항 친수공원 인공수로에 들어온 흑상어 **부캉이**를 방파제 너머 바다까지 탈출시키는 3D 3레인 러너 게임입니다.

- 좌우 스와이프(← → / A·D)로 라인 이동, 위로 스와이프(↑ / W / Space)는 점프, 아래로 스와이프(↓ / S)는 잠수입니다.
- 장애물마다 피격 범위(수면 표시 + 반투명 박스)가 실제 높이·깊이대로 표시됩니다. 통과 방법은 따로 알려주지 않고 장애물 모양으로 판단합니다.
  - 바닥에 묶인 것(체인 달린 부표, 흡입 호스·닻줄 달린 물펌프)은 라인 변경으로 피하기
  - 물 위로 높지만 밑이 비어 있는 것(그물 커튼, 사람이 서 있는 구조 보트)은 잠수
  - 낮게 떠 있는 것(부유물, 오일펜스)은 점프 또는 잠수
- 고등어를 먹으면 점수, 세 번 부딪히면 실패합니다.
- 시작 화면에서 난이도를 고릅니다(마지막 선택을 기억, 최고 기록은 난이도별로 따로 저장).
  - 보통: 12 → 22 m/s, 장애물 간격 1.6 → 0.85초, 세 라인이 모두 막힌 줄 6 → 25%
  - 어려움: 13 → 26 m/s, 장애물 간격 1.25 → 0.62초, 세 라인이 모두 막힌 줄 14 → 40%, 라인으로 끼어드는 구조 보트가 더 자주 등장
- 총 1,400 m: 친수공원 수로(0–1,040 m) → 북항 → 방파제 등대 사이(1,400 m) 통과 시 성공.

`index.html` 하나로 동작합니다(Three.js r128을 cdnjs에서 불러옴). 빌드 과정이 없습니다.

### 실행
- 로컬: `index.html`을 브라우저로 열거나 `python3 -m http.server` 후 접속.
- 공유: GitHub 저장소 Settings → Pages → Branch를 이 파일이 있는 브랜치로 지정하면 `https://<사용자>.github.io/AnyGame/` 주소로 누구나 플레이할 수 있습니다.

### 친구 랭킹
- claude.ai 게임 링크에서만 동작합니다(아티팩트 공유 DB). 난이도별로 한 사람당 가장 빠른 완주 기록 1개가 저장됩니다.
- 완주 후 결과 화면에서 이름을 정해 등록하고, 시작 화면의 "친구 랭킹"에서 순위를 봅니다.
- 기록을 올리려면 해당 아티팩트에 쓰기 권한(같은 팀 멤버이거나 편집자 초대)이 있어야 합니다. 공개 링크로 들어온 외부 방문자는 보기만 가능하고, 로그아웃 상태에서는 랭킹이 보이지 않습니다.
- GitHub Pages 사본에서는 랭킹 대신 안내 문구만 표시됩니다.
